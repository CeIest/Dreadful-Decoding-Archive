# Dreadful Decoding Archive

Currently hosted on https://dreadfuldecoding.argos-cats.com/.  


## Contribution  

### Project overview  
The website's content is located in the [`content/posts`](content/posts) directory.  
All pages are written in Markdown.

If you wish to contribute to the archive, feel free to submit a pull request.


### Editor
The project currently uses [Hugo v0.143.1](https://github.com/gohugoio/hugo/releases/tag/v0.143.1).  
If you wish to run the website locally, simply drop your Hugo binary in the repo's root directory and run `hugo server` in your CMD.


## Content guidelines
• For consistency, please follow the existing Markdown formatting.  

• If you wish to add content from the former website, please make sure it hasn't already been licensed in English. If you're unsure about something, please contact me first.  

• This is an archive. Aside from correcting typos, please do not modify existing content or add any original material.  

• Manga-related content is not allowed.  

• Use of AI is strictly not allowed.
